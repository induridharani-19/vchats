## 🛠️ Quick Local Setup

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Access the application interface at `http://localhost:5173`.

### 3. Docker Setup
```bash
docker-compose up --build
```
